Nanma (നന്മ) privacy policy

Last updated: 18 October 2026

Nanma is a Malayalam practice app for learners in our Malayalam classes, from young children to adults. We built it to collect as little as possible. In short: Nanma collects no personal information, has no accounts, no ads, no analytics and no tracking.

What stays on your device

  • Learner profiles: the name or nickname you type, the chosen animal, level and settings.
  • Progress: stars, finished activities, missed words, streaks.
  • Voice recordings: when a learner taps "Say it", the recording is saved on the device so they can compare it with the teacher's voice. Recordings are never uploaded or shared.

None of this leaves the device. Deleting a profile, or the app, deletes it.

Microphone

Nanma asks for the microphone only for the "Say it" practice above. It is never used in the background.

What Nanma downloads

The app downloads lesson content (words, pictures, recordings) and a list of enrollment codes from our content site on GitHub Pages. The code list contains no names: each code is stored as a one-way scrambled value, and the code a learner types is checked on the device. Like any website, GitHub may keep standard server logs (such as IP addresses) when content is downloaded; see GitHub's privacy statement. We do not receive or keep that information.

Children

Nanma is designed for children with their families and teachers. Because it collects no personal information, there is nothing to share with anyone. A grown-up sets up each learner's profile and enters the code from the teacher.

Changes

If this policy changes, we will update this page and the date above.
